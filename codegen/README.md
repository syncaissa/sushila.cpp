# Sushila CodeGen (sushilaCodeGen.cpp)

Write, explain and fix programs in many languages (Python, JavaScript/TypeScript, C/C++, Java, Go, Rust, SQL, shell, ...),
locally and privately.

**What happens after you click Next -> Install -> Finish:**
1. The app installs Sushila.cpp for your graphics card (or reuses the one another Sushila app already installed).
2. It installs a coding model that fits your computer: **Qwen3-Coder 30B-A3B Instruct** with 24 GB+ of memory (only 3B
   parameters active per token, so it is quick even on a CPU), **Qwen2.5-Coder 7B Instruct** otherwise. Apache-2.0,
   signed by Sushila, every file checked by sha256.
3. It starts the model and opens a chat with a first request (a fast Fibonacci function with tests). Answers show code
   blocks with their language and a **Copy** button; **⛶ Maximize** gives the conversation the whole window.

All Sushila products are one app: installing another one only adds its model. Download:
[GitHub Releases](https://github.com/syncaissa/sushila.cpp/releases) (`sushilaCodeGen.cpp-<version>-<system>`) or
https://sushila.ai/hoststation.
