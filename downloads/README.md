# Sushila downloads

Installers and engine builds are published as [GitHub Releases](https://github.com/syncaissa/sushila.cpp/releases) of this
repository, with a permanent copy on Sushila's own storage (same sha256). This page lists them with their sha256 sums
and is rewritten by `scripts/hoststation/publish_release.py` at every release.

| Download | What it is |
|---|---|
| `sushilaImageGenerator.cpp` | pictures from a sentence: installs the engine, Z-Image-Turbo and the app, then draws "Two bears dancing in a forest near a river" |
| `sushilaMusicGenerator.cpp` | songs from lyrics and a style (ACE-Step 1.5) |
| `sushilaHostStation.cpp` | runs any Sushila model pack (chat, images, music) and shares it on your network |
| `sushila.cpp` | the engine; installed automatically by the apps above, which pick the right build for your graphics card |

The first release (0.1.0) is being built. Easiest way meanwhile: https://sushila.ai
