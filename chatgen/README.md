# Sushila ChatGen (sushilaChatGen.cpp)

A private assistant that runs on your own computer: nothing you type leaves it.

**What happens after you click Next -> Install -> Finish:**
1. The app installs Sushila.cpp for your graphics card (or reuses the one another Sushila app already installed).
2. It installs a chat model that fits your computer: **Qwen3 30B-A3B** with 24 GB+ of memory (a fast mixture of experts),
   **Qwen3 4B Instruct 2507** otherwise. Both Apache-2.0, signed by Sushila, every file checked by sha256.
3. It starts the model and opens a chat, right in the app. **⛶ Maximize** shows only the conversation; **Restore** brings
   the controls back. **Open in browser** opens the same chat in your web browser.

All Sushila products (ChatGen, CodeGen, ImageGen, MusicGen, Host Station) are one app: installing another one only adds
its model. When apps are installed locally, you are the King (or Queen!)

Download: [GitHub Releases](https://github.com/syncaissa/sushila.cpp/releases) (`sushilaChatGen.cpp-<version>-<system>`)
or https://sushila.ai/hoststation.
